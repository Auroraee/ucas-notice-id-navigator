# UCAS 教务通知检索脚本 v1.4.1

用于中国科学院大学教务系统通知页面的篡改猴脚本，提供通知 ID 导航、范围检索、单框布尔表达式、可拖动悬浮球，以及可配置的请求间隔。

## 安装或更新

1. 在浏览器中启用篡改猴（Tampermonkey）。
2. 打开 [安装 / 更新脚本](https://raw.githubusercontent.com/Auroraee/ucas-notice-id-navigator/main/new-ucas-notice-id-navigator.user.js)，按扩展提示安装；也可将 `new-ucas-notice-id-navigator.user.js` 的完整内容替换到篡改猴中的原脚本并保存。
3. 登录 [UCAS 教务系统](https://jwxk.ucas.ac.cn/)，进入通知页面并刷新。

只启用一个版本，避免旧版与新版同时运行。扫描请使用 HTTPS；本脚本不提供登录或访问权限。

### v1.4.1 修复

- 修复页面在 100% 缩放或窗口较矮时，结果列表被压缩到无法查看的问题。面板内容和结果列表均可滚动，顶部“结果”按钮可直接定位并聚焦列表。
- 支持反馈中通知页面的 `.mc-body > h3` 标题及紧邻的正文 `div`，包括标题以“说明”结尾的课程通知；不会将“查看通知-选课系统”当成通知标题。
- 更新后重新扫描需要查询的 ID 范围，旧解析规则生成的缓存会重新检查，即使勾选“跳过已完成”也不会阻止这次更新。不必清空关键词和频率设置。

## 单个输入框组合关键词

在“关键词表达式”中输入 `AND`（与）、`OR`（或）、`NOT`（非），使用括号组合任意条件。例如：

```text
选课 AND (秋季 OR 春季) AND NOT (补选 OR 取消)
```

表示：包含“选课”，同时包含“秋季”或“春季”，并且不包含“补选”和“取消”。

| 表达式 | 含义 |
| --- | --- |
| `选课 AND 通知` | 两个关键词都出现 |
| `选课 OR 考试` | 任意一个出现 |
| `选课 AND NOT 补选` | 包含选课，排除补选 |
| `(选课 AND 秋季) OR (考试 AND NOT 补考)` | 两组条件满足任意一组 |
| `NOT (补选 OR 取消)` | 同时排除补选和取消 |
| `"AND" OR "OR"` | 查找运算符文字本身 |

- 优先级：括号最高，其次 `NOT`、`AND`、`OR`。例如 `A OR B AND C` 等同于 `A OR (B AND C)`。
- 运算符不区分大小写，应与关键词用空格或括号分开。支持中英文括号；不带运算符的相邻词默认使用 `AND`，例如 `选课 通知`。
- 用双引号或中文双引号包住含空格、括号、运算符的关键词，例如 `"学术 英语"`、`"课程(一)"`。引号中可用 `\"` 或 `\\` 表示双引号或反斜杠。
- 关键词匹配沿用忽略英文大小写、全半角和文字间空白的规则；引号用于把内容视为一个关键词，不代表按英文单词边界或原始空白精确匹配。
- 输入框下方的 `AND`、`OR`、`NOT` 和 `()` 按钮可在光标处插入运算符；选中文字后点 `()` 或 `NOT` 可以包住所选表达式。
- 留空时不限制结果。表达式有误时显示错误位置，暂停筛选并阻止新扫描和复制；已抓取的记录保留，正在运行的扫描仍可继续或停止。
- 最长 8192 个字符，括号或 `NOT` 嵌套最多 64 层；过于复杂的表达式会提示简化。
- “标题 + 全文”会搜索标题和正文的全部已保存文字，展示摘要的长度不影响检索。附件内部文字不在搜索范围内。
- 正文尚未完整时，逐个条件按“符合 / 不符合 / 未知”计算整个表达式；无法确认的结果显示“待检查”。例如标题已经包含“选课”时，`选课 OR 奖学金` 可确认命中，而 `选课 AND NOT 补选` 仍需确认全文。“只看命中 / 待检查”会保留这些记录。
- 修改关键词立即筛选已有结果，不自动发起请求。需要补齐正文时，切换到“标题 + 全文”后对相应范围再次扫描；仅有标题的缓存不会被跳过。
- v1.3.0 的三组关键词和更早版本的关键词设置会自动转换为等价表达式，旧关键词中的运算符文字会加引号保留。

## 可移动悬浮球

- 点击面板右上角的“−”将整个面板收起为悬浮球；点击球可重新展开。
- 用鼠标或触屏拖动悬浮球，松手保存位置；拖动结束不会误触展开。
- 收起状态和球的位置会保留，刷新或进入另一条通知后恢复；窗口缩小时自动限制在可见区域内。
- 聚焦悬浮球后可用方向键移动，按住 Shift 可加大步长；Enter 或空格可展开。
- `Alt+N` 在面板与悬浮球之间切换。收起不会停止扫描，球上的文字会显示“扫描”或“暂停”状态。
- 面板高度随窗口调整；内容超出时可在面板内上下滚动。顶部“结果”按钮始终可见，点击后可用滚轮或 Page Up / Page Down 浏览结果列表。

## 请求频率与操作

- 首次使用或未选择自定义时，采用推荐配置：每次抓取结束后等待 3～5 秒。
- 可展开“检索频率”，选择自定义最小、最大间隔。单位为秒，两值相同表示固定间隔；有效范围为 0.001～86400 秒，且最小值不能大于最大值。
- 请求始终串行。HTTP、自动回退的 iframe、失败重试共用调度入口。运行中修改频率，下次任务生效。
- 间隔记录和服务器冷却保存在本地；重新启动任务、刷新或切换同源标签页不会重置等待。
- HTTP 返回 429 时遵守 `Retry-After`，缺失或无法解析时默认冷却 60 秒；503 携带该头时也会等待。连续网络/服务器错误会暂停后续请求，可选择继续或停止。
- iframe 页面响应的 HTTP 状态码和响应头无法通过 DOM 直接读取，因此强制 iframe 模式不能保证识别服务器的 429 和 `Retry-After`。
- 使用浏览器 Web Locks 防止同源标签页同时扫描。扫描需要支持该能力的浏览器和安全上下文，学校页面请使用 HTTPS。能力不可用时仍能导航和筛选缓存，并会提示原因。
- “停止”会取消等待、活动 fetch 和 iframe；保留已经完成的记录。
- “跳过已完成”按当前标题/全文模式判断。取消勾选或使用“强制重扫”可重新获取；解析失败可重试，404 缓存一天。
- “重试失败项”直接使用失败 ID 清单，不展开最小 ID 到最大 ID 的整个范围。每次任务最多 3000 条。
- 普通点击结果标题会打开新标签页，旁边的 `↵` 在当前标签页打开。

“抓列表”“一键找选课”和启动时的自动网络探测已移除。

## 缓存与解析

- 设置保存在 `localStorage`；当前分类的检索结果保存在本标签页的 `sessionStorage`。结果不构成跨标签页的共享数据库。
- 兼容旧关键词设置和缓存。解析规则升级时，旧缓存保留供查看，但正文完整标记会失效；下次扫描会按新版规则重新读取，包括标题模式。
- 正文与摘要分开处理；缓存空间不足时只持久化标题并明确标记正文不完整，本页内存中的全文仍可检索。
- 登录判断使用明确的域名/路径和登录表单特征，避免将 `ucas` 中的 `cas` 当作登录地址。iframe 也会检查登录页。
- 发布日期只从明确的发布元数据或“发布日期/发布时间/发布于”文字提取，无法确认则留空。
- 正文完整度依赖页面结构、加载标记和 iframe 内容稳定性判断。学校页面结构变化、图片正文或持续异步加载仍可能需要调整解析规则。

## 离线验证

安装测试依赖后运行：

```powershell
npm ci --ignore-scripts
npm run check
npm test
```

测试依赖只供开发验证，安装和运行篡改猴脚本不需要 Node.js 或 npm。

回归测试使用 jsdom、模拟时钟和模拟 HTTP/iframe 响应，不访问学校网站。覆盖表达式优先级与嵌套、语法错误、旧条件迁移、正文完整度、缓存、登录识别、请求调度、冷却、停止、重试，以及悬浮球拖动、位置恢复和边界限制。

已安装 Microsoft Edge 或 Google Chrome 时，还可运行实际浏览器布局测试：

```powershell
npm run test:layout
```

默认先尝试 Edge，再尝试 Chrome；可用环境变量 `UCAS_TEST_BROWSER=chrome` 指定 Chrome。该测试使用新的无头浏览器会话，在 100% 页面缩放下检查 7 种窗口尺寸（含 1366×650、390×640、1280×300），验证面板边界、滚轮、键盘滚动与“结果”定位。所有页面请求均被拦截为本地测试内容，不使用已有浏览器登录状态，不访问学校网站。测试截图写入已忽略的 `.local-debug/`。

v1.4.1 已通过 43 项离线回归测试和上述 7 种尺寸的布局验证。解析测试基于反馈中的页面结构；尚未在已登录的学校网站上复核 794、795 的实际响应。
