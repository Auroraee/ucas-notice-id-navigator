# UCAS 教务通知检索脚本 v1.3.0

用于中国科学院大学教务系统通知页面的篡改猴脚本，提供通知 ID 导航、范围检索、与/或/非关键词筛选，以及可配置的请求间隔。

## 安装或更新

1. 在浏览器中启用篡改猴（Tampermonkey）。
2. 打开 [安装 / 更新脚本](https://raw.githubusercontent.com/Auroraee/ucas-notice-id-navigator/main/new-ucas-notice-id-navigator.user.js)，按扩展提示安装；也可将 `new-ucas-notice-id-navigator.user.js` 的完整内容替换到篡改猴中的原脚本并保存。
3. 登录 [UCAS 教务系统](https://jwxk.ucas.ac.cn/)，进入通知页面并刷新。

只启用一个版本，避免旧版与新版同时运行。扫描请使用 HTTPS；本脚本不提供登录或访问权限。

## 仓库文件

- `new-ucas-notice-id-navigator.user.js`：可直接安装的完整脚本。
- `tests/regression.test.cjs`：离线回归测试。

## 关键词的与、或、非

三组条件同时生效，组内用空格分词，留空的组不限制结果。

| 输入框 | 规则 | 示例 |
| --- | --- | --- |
| 全部包含 · 与 | 每个词都需要出现 | `选课 通知` |
| 任一包含 · 或 | 至少出现一个词 | `秋季 春季` |
| 排除词 · 非 | 任意一个词出现就排除 | `补选 取消` |

上述示例表示：包含“选课”和“通知”，同时包含“秋季”或“春季”，并且不包含“补选”和“取消”。

- 使用三个输入框组合条件，无需输入 `AND`、`OR`、`NOT` 或括号；这些字符不会被解释为运算符。
- 匹配忽略英文大小写、全半角和文字间的空白。空格用于分词，目前不提供带空格的精确短语语法。
- “标题 + 全文”会搜索标题和正文的全部已保存文字，展示摘要的长度不影响检索。附件内部文字不在搜索范围内。
- 正文尚未完整时，缺失的关键词或无法确认的排除条件显示为“待检查”，不会直接记为不符合。“只看命中 / 待检查”会保留这些记录。
- 修改关键词立即筛选已有结果，不自动发起请求。需要补齐正文时，切换到“标题 + 全文”后对相应范围再次扫描；仅有标题的缓存不会被跳过。

## 请求频率与操作

- 首次使用或未选择自定义时，采用推荐配置：每次抓取结束后等待 3～5 秒。
- 可展开“检索频率”，选择自定义最小、最大间隔。单位为秒，两值相同表示固定间隔；有效范围为 0.001～86400 秒，且最小值不能大于最大值。
- 请求始终串行。HTTP、自动回退的 iframe、失败重试共用调度入口。运行中修改频率，下次任务生效。
- 间隔记录和服务器冷却保存在本地；重新启动任务、刷新或切换同源标签页不会重置等待。
- HTTP 返回 429 时遵守 `Retry-After`，缺失或无法解析时默认冷却 60 秒；503 携带该头时也会等待。连续网络/服务器错误会暂停后续请求，可选择继续或停止。
- iframe 页面响应的 HTTP 状态码和响应头无法通过 DOM 直接读取，因此强制 iframe 模式不能保证识别服务器的 429 和 `Retry-After`。
- 使用浏览器 Web Locks 防止同源标签页同时扫描。扫描需要支持该能力的浏览器和安全上下文，学校页面请使用 HTTPS。能力不可用时仍能导航和筛选缓存，并会提示原因。
- “停止”会取消等待、活动 fetch 和 iframe；保留已经完成的记录。
- “跳过已完成”按当前标题/全文模式判断。取消勾选或使用“强制重扫”可重新获取；解析失败可重试，404 缓存一天。
- “重试失败项”直接使用失败 ID 清单，不展开最小 ID 到最大 ID 的整个范围。每次任务最多 3000 条。
- 普通点击结果标题会打开新标签页，旁边的 `↵` 在当前标签页打开。

“抓列表”“一键找选课”和启动时的自动网络探测已移除。

## 缓存与解析

- 设置保存在 `localStorage`；当前分类的检索结果保存在本标签页的 `sessionStorage`。结果不构成跨标签页的共享数据库。
- 兼容旧关键词设置和缓存。旧版正文完整标记会失效，需要补齐后才按完整正文使用。
- 正文与摘要分开处理；缓存空间不足时只持久化标题并明确标记正文不完整，本页内存中的全文仍可检索。
- 登录判断使用明确的域名/路径和登录表单特征，避免将 `ucas` 中的 `cas` 当作登录地址。iframe 也会检查登录页。
- 发布日期只从明确的发布元数据或“发布日期/发布时间/发布于”文字提取，无法确认则留空。
- 正文完整度依赖页面结构、加载标记和 iframe 内容稳定性判断。学校页面结构变化、图片正文或持续异步加载仍可能需要调整解析规则。

## 离线验证

安装测试依赖后运行：

```powershell
npm ci --ignore-scripts
npm run check
npm test
```

测试依赖只供开发验证，安装和运行篡改猴脚本不需要 Node.js 或 npm。

回归测试使用 jsdom、模拟时钟和模拟 HTTP/iframe 响应，不访问学校网站。覆盖布尔筛选、正文完整度、缓存迁移与配额、登录识别、请求间隔、跨标签页锁、冷却、停止、重试和界面交互。

本次未进行已登录学校网站上的真实浏览器验证。
